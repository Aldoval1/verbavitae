# Dictionary materials

These files are stored locally so the animation does not depend on a texture CDN.

- `brown-leather.jpg`: **Brown Leather**, Rob Tuytel / Poly Haven, 1K diffuse map.
  Source: https://polyhaven.com/a/brown_leather
  License: CC0 1.0, https://polyhaven.com/license
- `paper.jpg`: **Paper 001**, ambientCG, 1K color map.
  Source: https://ambientcg.com/view?id=Paper001
  License: CC0 1.0, https://docs.ambientcg.com/license/

Book geometry, cover typography, dictionary entries and scroll choreography are composed in HTML/CSS/JavaScript. The Creative Lab entry is an editorial description of Verba Vitae, not a quotation from a published dictionary.

3D rendering: Three.js 0.170.0, MIT license; see `js/vendor/THREE-LICENSE.txt`. Book meshes and leaf deformation are authored in `js/dictionary-webgl.js`.
